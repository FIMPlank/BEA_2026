# BEA 2026

Landing page and collection of standalone KI-Praxisprojekte for BEA 2026.

## Structure

- `index.html` — landing page linking to each project
- `kuechen-manager-pro/` — IHK Kantine, Wochenplanung-Cockpit (live, Gruppe 1)
- `gfft-food-feedback/` — GFFT, Gamified Food Feedback Tool (live, Gruppe 2)
- More projects will be added as their own subfolders, each linked from the landing page.

## Hosting

Static site, no build step. Deploy via GitHub Pages from the repo root (branch `main`, folder `/`).
